# ZCode 速度悬浮条

ZCode 状态条：实时速度显示进度条。

本工具本地使用不联网，工具在 ZCode 进程内读取会话状态，不读取账号凭据，不把消息正文或工具返回内容写入状态文件和日志。远程会话沿用 ZCode 已有的远程连接。

| 环境    | 要求      |
| ------- | --------- |
| Node.js | node      |
| ZCode   | v3.17.1 + |

## 安装

支持 Windows/Linux/macOS。

```
https://github.com/TTT1231/zcode-speed-bar/blob/main/skill/zcode-speed-repair/SKILL.md install it
```
